# 業務與入單部 (Sales & Onboarding)

**目標**：把名單變成成交客戶，乾淨地交給教練交付部。

## 標準流程
1. 名單進來 → 用 `../templates/discovery-call-script.md` 做諮詢（診斷，不推銷）。
2. 配對**一個**方案（`../offers/packages.md`）→ 用 `../templates/client-package-proposal.md` 出單。
3. 成交 → 收訂金 → 填 `Personal Training Client Sign-up Form`（Drive 既有表單）。
4. 記進 `../templates/finance-record.md` 漏斗。

## 交接給教練交付部（Onboarding 清單）
- [ ] 客戶基本資料 + 目標 + 作息
- [ ] 方案與效期
- [ ] 建立 `../templates/progress-tracker.md`
- [ ] 首堂時間

## 原則
高階客戶重質感與時間效率；不折扣壓迫、不恐懼行銷。
