# 企業 B2B 部 (Corporate Wellness)

**目標**：用企業客戶做高單價、可複製的增長線（一單抵多個個人客戶）。

## 流程
1. 詢問進來 → 用 `../templates/corporate-proposal.md` 出提案。
2. 附講師簡介 `ANG JIAN LE Profile.pdf`（Drive）。
3. 方案：單場工作坊 / 系列計劃 / 高管一對一。
4. 成交 → 記進 `../templates/finance-record.md` 的 B2B 營收。

## 既有資產（可複用，別重做）
- Corporate Fitness Workshop.pdf
- [ZERA] Corporate Wellness Workshop
- Athlite Fitzone x Ascenity（合作案例）

## 為什麼重要
企業客戶客單高、可系統化交付、且能帶來一批潛在個人客戶（員工）。這是從「一人教練」放大到「公司」的最快路徑。
