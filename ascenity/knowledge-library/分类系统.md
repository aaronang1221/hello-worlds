# Ascenity 知識庫分類系統（07 Knowledge Library）

> 用途：把 iCloud 的 `ASCENITY/07 Knowledge Library` 底下的書籍分類、命名、建索引。
> 用法：把書名清單貼給 Elsa／Claude，會依這套架構自動把每本書歸位，填進下方索引表；或你自己照這套資料夾結構把檔案拖進去。

## 資料夾結構（8 大類，直接在 07 Knowledge Library 底下開）

```
07 Knowledge Library/
├── A_訓練與運動科學/        肌力、體態、運動解剖、居家訓練、動作矯正
├── B_營養與飲食/            運動營養、減脂增肌、飲食法、在地飲食
├── C_健康老化與長壽/        Active Aging、50+、銀髮、荷爾蒙、睡眠
├── D_商業與行銷/            獲客、社群經營、內容變現、品牌、文案
├── E_心態與自我成長/        心理學、習慣、致富心態、情緒
├── F_時間管理與高效/        生產力、時間管理、專注
├── G_領導與經營/            領導力、團隊、企業經營、管理
└── H_信仰與其他/            靈修、聖經、個人收藏、雜項
```

## 命名規則（統一後好搜、好排序）

`類別代號 - 書名 - 作者.副檔名`

- 例：`B - 運動營養全書 - 布朗蒂娜.pdf`
- 例：`E - 致富心態 - Morgan Housel.epub`
- 中英文都可以，作者不確定就留空：`A - 龙门架居家训练.pdf`

## 分類原則（歸類時的判斷）

1. **一本書只歸一類**：看它「主要在教什麼」，跨領域的書歸到最核心那一類。
2. **先看用途，再看主題**：如果一本商業書你主要拿來做內容行銷，就放 D，不放 G。
3. **拿不準就丟 H**，之後回頭再分，不要卡住。
4. 電子書格式（pdf / epub / mobi）不影響分類，只影響命名副檔名。
