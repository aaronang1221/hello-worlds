# Ascenity 企業作業系統 (Enterprise OS)

把 Ascenity 從「一個很忙的教練」變成「一家可複製、不重複的公司」。你是 CEO，底下 6 個部門由 AI 團隊 + 模版驅動。

## 檔案地圖

```
ascenity/
├── CLAUDE.md              ← 公司大腦：每個 session 先讀這份
├── README.md             ← 你在這
├── RECOMMENDATIONS.md    ← 最高槓桿的下一步建議
├── brand/brand-book.md   ← 品牌快速取用卡
├── offers/packages.md    ← 產品與定價（RM）
├── departments/          ← 6 個部門 SOP
│   ├── 00-org-map.md      （公司全景 + 客戶旅程）
│   ├── 01-marketing.md    → 一語成林團隊
│   ├── 02-sales-onboarding.md
│   ├── 03-coaching-delivery.md
│   ├── 04-client-success.md
│   ├── 05-finance-ceo.md
│   └── 06-corporate-b2b.md
└── templates/            ← 「不重複」模版庫
    ├── client-package-proposal.md   discovery-call-script.md
    ├── session-plan.md   diet-plan.md   progress-tracker.md
    ├── weekly-checkin.md   monthly-review.md
    ├── ig-carousel-brief.md   corporate-proposal.md
    └── finance-record.md
```

## 怎麼開始用

- **每天想做什麼，先找對應部門**（`departments/00-org-map.md` 有全景）。
- **要產出任何東西前，先看 `templates/` 有沒有現成的**——有就套、沒有就先建再用。這是「不重複」的鐵律。
- **行銷** 說「Elsa／一語成林」喚醒團隊。
- **每月月底** 更新 `templates/finance-record.md`，回答 CEO 三問。
