# 我的工作流程：30 天獲客內容月曆系統

> 這是使用者本人的內容工作流程，從 Notion「🗓️ 30天獲客內容月曆系統」轉移過來。
> 一語成林團隊（Elsa 與五官）產內容時，**排程與漏斗節奏一律照這份走**，取代 SKILL.md 裡通用的 30 天邏輯。
> 上傳官（lin-uploader）產日曆、裂變設計師（lin-designer）決定每篇漏斗階段時，都以本檔為準。

## 核心原則

一週一個**行銷支柱（Pillar）主題**，所有內容**以終為始、逆向產出**。每一天都掛一個 CTA，導回那週支柱的行銷重點。先決定「這週要賣什麼」，再長出每天的貼文。

## 兩層資料結構（先支柱、再行事曆）

先填「① 內容支柱」決定本週主題與 CTA，再到「② 貼文行事曆」把每天的內容長出來。

### ① 內容支柱 Pillar（每週一列）

| 欄位 | 內容 |
|---|---|
| 週主題 / Pillar | 這週的支柱主題（標題） |
| 週次 | 第1週／第2週／第3週／第4週 |
| 日期區間 | 這週的起訖日 |
| Pillar 形式 | 課程影片／YouTube 長片／部落格長文／Podcast／直播（本週的「母內容」形式） |
| 本週主 CTA | 加入 RemoteFAM／領取名單磁鐵／報名大師班／預約諮詢／加入 Skool 社群／導購課程 |
| CTA 連結 | 該 CTA 的實際網址 |
| 行銷重點 | 這週所有內容要導向的行銷訊息 |
| 靈感 / 研究 | 素材、觀察、研究筆記 |
| 本週內容 | 關聯到②行事曆這週的所有貼文 |

### ② 貼文行事曆 Posting Calendar（每天一張卡）

| 欄位 | 內容 |
|---|---|
| 標題 / Hook | 這則內容的主標／鉤子 |
| Hook A／B／C | 三個備選鉤子（A/B 測試用） |
| 日期／星期 | 發布日與週幾 |
| 平台 | 如 Skool、IG、Threads… |
| 格式 | 如 社群貼文、Reels、Carousel… |
| 漏斗階段 | TOF 啟發／MOF 教育／BOF 權威 |
| 本週 CTA | 自動帶入①支柱的「本週主 CTA」（rollup，不用重填） |
| 狀態 | 構思／草稿／已排程／已發布… |
| 每週重複 | 是否為固定週更欄位 |
| 腳本 / 文案 / 筆記 | 完整成品稿 |
| 連結 | 發布後的貼文連結 |

## 一週的漏斗節奏（產內容時照這個排漏斗階段）

- **週一 / 週二** → `TOF 啟發`：先把渴望點起來。
- **週三 到 週日** → `MOF 教育` 與 `BOF 權威` 自由混搭。
- **每一天** → 都掛一個 CTA，導回本週 Pillar 的主 CTA（例如報名大師班、領取名單磁鐵）。

> 對應 SKILL.md 品質把關第 3 條「啟發／教育／權威每週都要出現，權威型至少兩成」：本工作流程進一步鎖定了**時間位置**（週一二啟發、週三後教育＋權威），排日曆時直接照此填「漏斗階段」欄位。

## 三層檢視（交付時的呈現方式）

- **月**：月曆總覽 view，一眼看完整月排了什麼。
- **週**：本週看板 view，七欄＝週日到週六，最上面先看本週行銷主題。
- **日**：點開任一張卡片＝那則內容的完整編輯頁（Hook、腳本、截圖、連結全在裡面）。

## Elsa 落地規則

1. **開工先問這週的 Pillar 與主 CTA**：沒有本週主題與 CTA 終點就不產內容（呼應 SKILL.md 品牌根系鐵律）。
2. 上傳官（lin-uploader）產出的 30 天日曆，欄位、漏斗節奏、每日 CTA 一律套本檔格式，命名沿用 `內容日曆-主題-月份.md`。
3. 每篇成品稿在檔頭標注：`週次｜日期｜平台｜格式｜漏斗階段｜本週CTA`，方便回填 Notion 或匯出 CSV。
4. 要同步回 Notion 時，①支柱庫一週一列、②行事曆一天一卡，欄位名稱與上表一致。
