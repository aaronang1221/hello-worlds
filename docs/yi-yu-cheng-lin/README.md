# 一語成林 AI 內容團隊：安裝說明

一句話種下去，長出一座內容森林
這個包會在你的電腦裡裝一個 AI 內容團隊：總管兼教練 Elsa，加上五位官員（訪談官、分流官、裂變設計師、影片官、上傳官）。他們會帶你把一段錄音長成 30 天的跨平台內容。

## 安裝（只要三步）

1. 解壓縮這個 ZIP（你現在應該已經做完了）
2. 打開 Claude Code，把工作目錄切到這個資料夾（最快的方式：在這個資料夾裡開終端機打 `claude`，或直接把整個資料夾拖進 Claude Code）
3. 打這句話：

   請幫我安裝一語成林的助理團隊

就這樣，AI 會自己完成安裝，裝完 Elsa 會直接開始帶你上路。

## 之後怎麼用

安裝完成後，以後在任何資料夾開 Claude Code，說「Elsa」或「一語成林」就能喚醒團隊，建議幫你的內容開一個專屬資料夾（例如「我的內容森林」），在那裡面工作。

## 常見問題

**Windows 可以裝嗎？**
可以，步驟完全一樣，Claude Code 支援 Windows，安裝時 AI 會自動處理路徑差異。

**我用 Codex，不是 Claude Code，可以裝嗎？**
可以，一樣在這個資料夾裡打開 Codex，說同一句安裝指令，AI 會照 Codex 的方式安裝。差別是 Codex 沒有分身功能，Elsa 會自己一站一站做，產出品質一樣，只是大批產稿時速度慢一些。

**裝完要重開嗎？**
安裝當下 Elsa 就會直接開始帶你。之後開新對話時，說「Elsa」就能喚醒。

**會動到我電腦裡的其他東西嗎？**
不會，只會在你的家目錄底下的 `.claude` 資料夾放入技能檔案，全部都是文字檔。

**升級新版本怎麼辦？**
下載新的 ZIP，重複上面三步，AI 會問你要不要覆蓋舊版，回答「要」就完成升級。
